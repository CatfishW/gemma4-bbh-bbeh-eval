# Paper-grounded comparison assets

Read [the research plan](../../docs/SOTA_COMPARISON_PLAN.md) and
[command guide](../../docs/COMPARISON_SUITE.md).

`papers.json` records 22 method families, immutable inspected source blobs,
evidence/venue status, closest overlaps, and whether a method is executable here
or requires an upstream run. `datasets.json` covers 14 dataset groups and their
roles/scorer boundaries. `methods/` contains nine prompt controls; `training/`
contains five LoRA/RL controls, including CRAFT-Q. `study.json` contains proposed
budgets/seeds/acceptance criteria, not measured results or a registration claim.

Identity example values must be replaced before running. Existing CRAFT/VOLT
results remain unchanged. No raw datasets, checkpoint weights, API keys, new GPU
results, or fabricated paper-reproduction scores are included.
